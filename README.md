# Math Trainer — Level 2

Спрощена структура для навчання React.

## Структура

src/
├── components/
│   ├── Header/
│   ├── Quiz/
│   ├── Task/
│   └── Result/
├── data/
│   └── tasks.ts
├── App.tsx
├── main.tsx
└── index.css

## Що реалізовано

- useState
- useEffect
- таймер
- старт тесту
- перевірка відповіді
- правильна/неправильна відповідь
- підрахунок правильних відповідей
- відсоток правильних
- кнопка «Далі»
- Ultimate-режим
- фінальний результат
- повторне проходження

Задачі поки зберігаються у `src/data/tasks.ts`.
Генерацію випадкових задач додамо пізніше.
